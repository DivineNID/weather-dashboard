
## Stack technique

- **Vite** : outil de build et serveur de développement
- **JavaScript** : langage principal du projet
- **Tailwind CSS** : framework CSS pour le design et la mise en page
- **OpenWeather API** : récupération des données météorologiques
- **Node.js / npm** : gestion des dépendances et scripts du projet
- **Git / GitHub** : gestion de versions et hébergement du code
